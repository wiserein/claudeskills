# 审题与建模

> 建模是获奖的核心。评委最反感「只有算法没有模型」「全文同一方法」「模型简单无约束」。

## 一、选题策略（直接决定获奖概率）

- **理工科/数统/信科优先选 A/B 题**（数学物理题），获奖概率明显大于 C 题（数据分析题）。实例：有人做 C 题美赛、国赛两次失败，转 A 题即拿国二。原因：C 题数据难找、模型同质化、竞争大；A/B 题看似难，但看懂后套路固定。
- **C 题固定打法**：数据预处理（缺失值填充、去重、异常值箱线图、Z-score 标准化）→ 分布规律 → 相关性分析（皮尔逊）→ 预测 + 优化。仅统计/商科真正擅长数据分析的队才选。
- **赛前定选题**：训练时把 A、C 各做一遍，看哪种上手顺，别赛时临时试。
- **注意出题规律**：倒数第二问通常最难，最后一问反而简单（出题人考虑选手写不完）。

## 二、审题（吴孟达三层次 + 三步法）

### 三步法
1. **结构化分层阅读**：背景引入 / 条件叙述 / 建模目的要求，三层分开读。
2. **物理/机理情景构建**：还原机理，明确每个对象的运动方程或关系。
3. **约束条件识别**：标注所有隐含约束（如"折射率随波长变化""协同遮蔽""非中间位置不遮蔽"）。

### 吴孟达审题三层次（摘要/结论必须覆盖后两层）
| 层次 | 要求 | 论文体现 |
|------|------|---------|
| 第一层 | 表面理解：做了什么 | 模型清单、算法名称 |
| 第二层 | 本质理解：为什么这样做 | 问题数学本质归类、方法选择理由 |
| 第三层 | 深度理解：创新在哪 | 改进点的创新性、与已有方法的区别 |

- 看题后先和队友讨论 30 分钟明确"怎么做"，能讲清再动手写代码。
- 先答完题目要求，再谈拓展（没审题就拓展方向是坑）。

### 审题三层次（审题面 → 审细节 → 审逻辑）

- **审题面**：整体把握问题类型、现实背景、各问之间的逻辑关系。
- **审细节**：读出约束条件的每个细节（如"每条消息最多158字符""发送间隔≥1分钟""主站成功与否不独立"）。
- **审逻辑**：理清隐藏逻辑——读出题目未明确表达的含义，把握方向与节奏。

### 命题人方法论金句

- **问题是主角，方法是配角**：偏重方法的高/新/深、忽视问题本质，不可能产生有意义的创新。
- 建模能力 = **眼力 + 脑力 + 手力**；题目越贴近实际，对"眼力"（把握建模方向）要求越高。
- 实际问题的**考察粒度不同则假设可以不同**；先做简略估算排除次要因素（如塔的阴影按能量损失计影响千分之一以下，可忽略）。

### 命题人点名的审题失误（实例）

- 2022D：忽略"主站间成功与否不独立"（第二问关键）。
- 2021A FAST：力学+几何应简化为几何；"下拉索长度不变"大部分论文结果不满足；主索节点"径向移动"假设错误。
- 2019B：第三、四问基础条件完全不同，误认为"第三问建一般模型、第四问算具体结果"。
- 2016B：车辆通行模型严重缺乏针对性（放哪都可用=无价值）；评价指标要针对性、可计算、完备、紧凑。

## 三、递进式建模（从简单到复杂）

通用路线「先粗后精、层层加约束」：
1. 先用**最简单模型**跑通，拿到初值/可行解。
2. 再逐步精修加约束（实例：板凳龙 A 题 = 点模型→加宽度做碰撞检测→调螺距→调圆弧比例→求最大速度）。
3. 每个问题用**不同/递进**方法，禁止全文同一方法。

### 算法选择随维度升级
- 低维（≤4 变量）：PSO + 单纯形法（Nelder-Mead）。
- 高维（40 维）：PSO 易陷局部最优，改用差分进化 DE / JADE / MADS。
- 非线性最小二乘对初值敏感：先用网格搜索定大致范围，再精细迭代。

### 复杂度匹配原则（专家薛毅核心提醒）
**模型不能太简单也不能太复杂**——双光束模型已够精确就别硬上多光束修正；模型复杂度要匹配题目需求。

## 四、模型必须包含的要素

- **假设的合理性解释**（每条给成立理由 + 影响，非罗列，禁止"忽略其他次要因素"）。
- **完整建模逻辑链**：假设 → 变量 → 目标 → 约束 → 求解。
- **约束条件**：优化模型必须有约束，否则无法求解（高频扣分）。
- **多方法交叉验证**（≥2 种独立方法，如峰值法 vs FFT 法互证）。
- **误差分析**（含不确定度）。

## 五、模型验证（评审加分关键）

- 必做：残差分析、灵敏度分析、置信区间、多方法交叉验证。
- **蒙特卡洛模拟**是低成本高收益的验证手段（代码简单、能体现"做了检验"）。
- **物理意义核查**：厚度必须为正、折射率要合理、结果符合常识。
- 把不理想结果当 baseline：换模型后用"话术"体现新模型的改进，而不是放弃。

## 六、常见建模误区（扣分点）

1. 只有算法没有模型。
2. 全文四问都用同一方法（如全最小二乘）。
3. 只给最终模型，不给出推导过程。
4. 优化模型没有约束条件。
5. 机械套模型：K-means 不结合业务、只给 AUC 不解释阈值逻辑、照抄教科书。
6. 只用文字描述，不用数学公式（评分基础分丢失）。
7. 忽视题目隐含约束（折射率随波长变化却当常数，结果对也严重扣分）。
8. 差值模型不能外推预测；深度学习模型可靠性差，谨慎选用。
