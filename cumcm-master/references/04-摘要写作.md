# 摘要写作（决定第一轮筛选 80% 的去留）

> 摘要是全篇门面，评委 30 秒定去留。**第一天就开始写、改 3 版以上、最后数值全定后再终稿。**

## 评审流程（决定写作策略的关键事实）

- **初审：评委对每篇只有以分钟计的时间，只读摘要 + 粗略浏览全文，直接淘汰一半，且"再无翻身可能"。**
- 只有熬过前两轮（都是几分钟）才会被仔细阅读——首要目标是"顺利通过两个几分钟的评审"。
- 除摘要外，评委最易注意：**各小节标题、项目符号列表、表格、图形、数字**。禁止大段不间断文本。

## 一、结构模板

```
第1段（2-3句总起）：本文针对[问题]，建立了[模型体系]，采用了[方法框架]，
                    并通过[验证方式]论证了可靠性。

第2-N段（逐问一段）：针对问题X，[数学抽象]→[方法]→[关键数值结果]→[验证说明]。
                     每个问题各给一句核心公式 + 一个数值结论。

末段（2-3句）：模型评价 + 创新点 + 推广价值。

关键词：3-5个，按重要性排序。禁止引号、禁止编号。
```

## 二、硬性要求（违反即扣分）

1. **必须有具体数值**（如 `7.58±0.62 μm`），禁止"结果较好""效果显著""吻合良好"。
2. **必须有模型评价**（"模型收敛性好、多角度验证一致"）。
3. **必须逐问明确回答**，每个问题给结果 + 结果讨论。
4. 长度：半页至 2/3 页，不超过 1 页，且尽量占满一页。
5. 摘要**单独成页**。
6. **避免"针对问题n"套话开头**（多位评委明确反对）。

## 三、逐问写法（获奖范式）

每个问题一段，用 `\textbf{问题一（模型名）：}` 开头，包含：
- 数学抽象（用了什么原理/模型）
- 方法（算法名 + 一句话原理）
- 关键数值（**加粗**，带单位 + 不确定度 + 相对偏差/拟合优度）
- 验证（交叉验证、R² 等）

示例：
> **问题二（碳化硅厚度反演）：**设计了基于 SG 滤波、FFT 频谱分析和稳健波谷检测的三重交叉验证算法，得到外延层厚度为 **7.58±0.62 μm**（10°：7.51 μm，15°：7.64 μm，相对偏差 1.7%），R²=0.9996。

## 四、摘要必须覆盖吴孟达第二、三层

- 第二层（本质理解）：问题数学本质归类、方法选择理由。
- 第三层（深度理解）：创新点、与已有方法的区别。

## 五、高频摘要错误（448 条评阅意见高频出现）

1. 摘要无数值结果 / 结果表达不具体（最高频）。
2. 摘要无结果讨论、无模型评价。
3. "针对问题n"套话开头。
4. 摘要太短（两行）或太长（超一页）。
5. 摘要口语化、加粗太多。
6. 摘要只写问题一的结果，其他问没有。
7. 摘要含大量公式 / 数据罗列。
8. 摘要与正文没分页。
9. 摘要缺关键词。
10. 摘要背景描述太啰嗦（第一段太长）。

## 六、写作流程

1. 先各自独立写 → 合并 → 讨论 → 重写终版。
2. 由建模手主笔（最熟悉模型），论文手润色。
3. 最后等数值全定，用 `\ref{}`/`\textbf{}` 把最终数值填进摘要，与 `results/` CSV 核对一致。
