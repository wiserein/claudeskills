# AI 工具合规（2025 新规，不遵守 = 取消资格）

> 依据《全国大学生数学建模竞赛人工智能工具使用规定（2025年试行）》。

## 一、新规核心要求（施行日 2025-09-01）

1. **不强制使用**；未使用须在**参考文献之后**明确声明"本参赛队未使用任何 AI 工具"。
2. 可使用，但须遵循**公开透明原则**，核心建模与分析必须由参赛队独立完成。
3. **论文正文中**：使用 AI 生成的内容，在正文相应位置标注。
4. **参考文献中**列出所用 AI 工具，著录格式：
   `[编号] 工具名称, 版本/型号, 开发机构/公司, 使用日期`
   官方示例：`[1] DeepSeek, DeepSeek-R1-0528, 深度求索（DeepSeek）, 2025-09-05`
5. **支撑材料**：使用 AI 的作品必须在支撑材料中包含「AI 工具使用详情」说明（**PDF 格式、文件名"AI 工具使用详情"**），内容含 4 项：
   ① 所用 AI 工具名称和版本 ② 具体使用目的和环节 ③ 关键交互记录（重要提示词与回复）④ 采纳和人工修改情况
6. **罚则**：不符合上述要求的作品视为违反竞赛规则，**取消评奖资格**。

## 二、AI 工具使用详情怎么写

成品模板见 `templates/AI工具使用详情.md`，关键结构：

```
# AI工具使用详情
## 基本信息（队号 / 题目 / 队员）
## AI工具使用清单（每个工具独立成节）
   - 版本/型号、开发机构、使用日期
   - 使用目的与阶段
   - 关键交互记录（逐条"提示 → 产出"）
   - 采纳内容与修改说明
## 未使用AI的部分
## 声明
```

**关键技巧**：
1. "关键交互记录"写**具体提示词 + 具体产出**（有痕可查）。
2. "采纳与修改说明"强调**人工复核**。
3. 单独列"**未使用 AI 的部分**"，把建模/推导/撰写/判定划归人工——这是合规声明的核心策略。
4. 声明结尾固定"**工具赋能、人工主导**"八字原则。

## 三、使用边界（合规 + 质量双重要求）

- **只让 AI 写局部代码/局部数据处理**，不要全盘交给 AI 跑整个 project。
- 核心建模决策、公式推导、结果分析、论文撰写必须人工完成。
- AI 会一本正经编造不存在的方法/公式/改符号，**必须人工验证**。
- AI 生成的代码要理解逻辑再改。

## 四、AI 工具分工（获奖队伍实践）

| 场景 | 推荐工具 |
|------|---------|
| idea 构建与推理 | GPT-5 / Gemini 2.5 Pro |
| 写代码 | Claude / DeepSeek |
| 日常任务 | 豆包 / 千问 |
| 文件级 agent 编辑（直接读写文件、自动找 bug） | Codex / Cursor / VS Code agent |

- 提示词用 RTGO 公式（Role/Task/Goal/Output Format），分阶段迭代提问，CoT 展示推理。

## 五、AI 的高价值合规场景

- **代码审查**：让 AI 审查物理正确性/数值稳定性（获奖队借此发现 9 个 Bug）。
- **文献检索与验证**：检索并核实文献数据。
- **图表美化**：配色与样式优化。
- **数值核对**：论文数值与代码输出交叉核对。
- **格式检查**：LaTeX 格式、参考文献格式、图表引用一致性。
