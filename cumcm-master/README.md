# CUMCM 数学建模全流程大师（cumcm-master）

> **以国一为标杆**的全国大学生数学建模竞赛（CUMCM / 高教社杯）全流程指南。
> 整合历年国奖经验、448 条真实评阅意见、命题人审题视角、获奖项目完整范式，
> 覆盖「审题建模 → 编程求解 → 论文写作 → LaTeX 排版 → 图表 → AI 合规 → 格式检查 → 答辩」完整链条。

---

## 一、这是什么

一个可直接装进 Claude Code 的 **Skill**（技能包）。当你写数模论文、建模、编程时，它自动介入，按国一标准告诉你每一步该怎么做、该避免什么。

**核心定位：国一导向。** 不是"保底不违规、够拿国二"，而是把每一条判据、模板、扣分点都对准 **国一（95+）**。它回答的不只是"怎么做对"，更是"怎么做透"。

## 二、核心能力（7 大亮点）

1. **国一标尺（`11-国一标准.md`）**——"国一四问"分水岭：结果有没有锚点、问题闭不闭环、假设一手验没验、洞察是不是别人没有的。一眼定位论文是国一还是国二。
2. **448 条真实评阅意见归纳**——按频率排序的高频扣分点，写论文时逐条避雷。
3. **审题三层次 + 命题人方法论**——吴孟达三层次（表面/本质/深度）、审题面→细节→逻辑、命题人点名的审题失误案例。
4. **递进式建模范式**——从简单模型层层加约束，避免"全文同一方法"。
5. **摘要写作硬模板**——评审 30 秒定去留，每问必须给具体数值 + 核心公式 + 结果讨论。
6. **AI 合规（2025 新规）**——不遵守直接取消资格，含 `AI工具使用详情` 模板。
7. **零硬伤格式清单**——页边距、关键词、三线表、公式标点、GB/T 7714 参考文献，逐项打钩。

## 四、安装方法

1. **解压** `cumcm-master.zip`，得到 `cumcm-master/` 文件夹。
2. 把整个 `cumcm-master/` 文件夹复制到 Claude Code 的 skills 目录：
   - **Windows**：`C:\Users\<你的用户名>\.claude\skills\`
   - **macOS/Linux**：`~/.claude/skills/`
3. 重启 Claude Code（或新开一个会话）。
4. 输入 `/skills` 能看到 `cumcm-master` 即安装成功。

> 目录最终应为：`~/.claude/skills/cumcm-master/SKILL.md`

## 五、使用方法

**自动触发**：只要对话里提到「数学建模 / 数模 / 国赛 / 美赛 / 建模论文 / LaTeX / 摘要 / 灵敏度分析 / AI合规…」等任一关键词，skill 会自动加载。

**手动调用**：输入 `/cumcm-master` 直接进入。

**按阶段查模块**：skill 内部有路由表，做某件事就查对应文件（如写摘要 → `04-摘要写作.md`，交稿前 → `08-格式检查清单.md`，自查分档 → `11-国一标准.md`）。

**评分用法**：把论文（.tex / .pdf）交给 Claude，它会用「国一四问」给你打分并列出扣分细节与差距清单。

## 六、国一 vs 国二（一句话分水岭）

> **国二把题做完，国一把题做透。** 做透 = 结果有锚点、问题全闭环、假设一手验、洞察别人没有。格式只保证你不掉档，内容才决定你能不能上 95。

详见 `references/11-国一标准.md`。
