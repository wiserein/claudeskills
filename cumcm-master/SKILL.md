# CUMCM 数学建模全流程大师

整合历年国奖经验、448 条评阅意见、命题人审题视角、获奖项目完整范式的**国赛全流程指南**。覆盖：审题建模 → 编程求解 → 论文写作 → LaTeX 排版 → 图表 → AI 合规 → 格式检查 → 答辩。

> **一切以国一为标杆**：本 skill 的判据、模板、扣分点均指向国一（95+），不以"国二够用/格式合规"为终点。国一的分水岭判据见 `references/11-国一标准.md`。

## 一、核心铁律（任何时候都必须遵守）

> **国一导向**：十条铁律是"入场券"（保你不掉档），不是终点。上 95 靠"做透"——见 `references/11-国一标准.md` 的国一四问。

1. **摘要必须有具体数值**（如 `7.58±0.62 μm`），禁止"结果较好/效果显著"。
2. **全文不能同一方法**：每问用不同/递进方法，从简单模型演进到最终模型。
3. **正文不插代码**：代码放附录（伪代码）。
4. **三线表**：禁止全边框，表题在上、图题在下。
5. **参考文献 ≥5 条，不编号为"第X部分"**，GB/T 7714 格式。
6. **AI 必须申报**：支撑材料交 `AI工具使用详情.pdf`（2025 新规，不遵守取消资格）。
7. **页眉无队号/个人信息**（正式比赛违规）。
8. **重要公式单独成行 + 编号(1)(2) + 标点**。
9. **交叉验证 ≥2 种独立方法** + 灵敏度分析 + 误差分析。
10. **论文数值与代码输出一致**（`results/` CSV 是唯一事实源）。
11. **国一四问自查**：结果有锚点？问题全闭环？假设一手验？洞察别人没有？（详见 `references/11-国一标准.md`）

## 二、全流程时间线（国赛四天）

| 时间 | 任务 |
|------|------|
| D1 | 选题（1h 内）+ 查文献 + 收集数据 |
| D2-D3 | 攻代码 + 边写论文（一问一问同步写） |
| D4 | 专写论文 + 摘要终版 + 格式检查打钩 |

**九步完整步骤链**：读题建模（人工主导）→ 写主求解器、数值落盘 → 代码审查修 Bug（AI 辅助）→ 绘图 → 写论文 LaTeX → AI 辅助润色 + 合规 → 排版编译 → 做 PPT → 交付整理。

## 五、关键原则

- **数值结果（`results/` CSV）是「代码 → 论文 → PPT」三者的唯一事实源**，任何数值改动都从代码重新生成并回写三处。
- **摘要第一天就开始写，改 3 版以上**，由建模手主笔，最后数值全定再终稿。
- **论文一问一问同步写**，不能堆到最后。
- 团队**严禁割裂分工**，三人都会一点，交叉核对。
- **交稿前 8 点后不再改论文**。

## 六、使用方式

- 用户提到"数学建模/国赛/数模论文"等触发词时自动加载本 skill。
- 根据用户当前所处的阶段（审题/建模/编程/写作/排版/提交），读取对应 reference 模块获取详细规范。
- 需要产出成品时，直接引用 `templates/` 下的模板。
- 用户已有论文/代码时，用 `references/09-评阅扣分点.md` + `references/08-格式检查清单.md` 做对照审查，**并用 `references/11-国一标准.md` 的"国一四问"定位档位**（格式只决定国二档内高低，内容才决定能否上 95）。
