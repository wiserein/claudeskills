# 格式检查清单（赛前 3 小时逐项自检）

> 提交前逐项打钩。任何一项没做都可能直接扣分或违规。

## 一、身份与页码

- [ ] 页眉**无队号、无个人信息**（正式比赛直接违规）
- [ ] 有承诺书
- [ ] 页码从正文第 1 页开始（封面 + 摘要不编页码，一般从第 3 页起）

## 二、摘要

- [ ] 摘要**单独成页**、≤1 页、尽量占满一页
- [ ] 每问有**具体数值** + 结果讨论 + 模型评价
- [ ] 有关键词（5-8 个）
- [ ] 无"针对问题n"套话开头

## 三、图表

- [ ] 所有表格是**三线表**（无全边框）
- [ ] 所有图表有**编号 + 标题 + 正文引用**
- [ ] 表题在表上方、图题在图正下方
- [ ] 无截图、无水印、无高饱和彩色
- [ ] 图片 ≥300dpi、白底、中文字体清晰

## 四、公式

- [ ] 重要公式单独成行 + 编号(1)(2)（英文半角括号）
- [ ] 公式后有标点
- [ ] 变量斜体、公式无虚框、无截图

## 五、正文

- [ ] 正文**无代码**（放附录）、无程序运行截图
- [ ] 章节层次分明（1, 1.1, 1.1.1），不跳跃
- [ ] 标点正确、字体统一、无红色/过大字体
- [ ] 无英文与中文混杂未说明

## 六、参考文献

- [ ] ≥5 条（建议 8-15 条）
- [ ] **不编号为"第X部分"**
- [ ] GB/T 7714 格式、两端对齐、期刊不带 DOI/网址

## 七、AI 合规

- [ ] AI工具使用详情.pdf 在支撑材料中
- [ ] 参考文献列了 AI 工具（如使用）；未用则声明"未使用任何AI工具"
- [ ] 论文正文 AI 生成内容已标注

## 八、数值核对

- [ ] 论文所有数值与代码输出 CSV **一致**
- [ ] 代码可复跑、结果一致
- [ ] 小数位与题目精度一致（一般保留 3 位）

## 九、最终动作

- [ ] 编译 0 错误（XeLaTeX）
- [ ] 删除旧版/冗余文件，保留最终版
- [ ] 交稿前 8 点后不再改论文
