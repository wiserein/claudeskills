# 论文写作总纲

## 一、论文标准结构

封面 → 承诺书 → 摘要（单独页）→ 目录 → 正文 → 参考文献 → 附录

正文标准结构（国赛通用）：
1. **问题重述**（背景 + 重述 + 分析）
2. **模型假设与符号说明**（表）
3. **模型的建立与求解**（逐问）
   - 每问内部：问题分析 → 模型建立 → 算法设计 → 结果分析 → 模型检验
4. **模型评价与改进**（优点 + 不足 + 改进方向）
5. **结论**
6. **附录**：核心算法伪代码 / 程序文件清单

> 备注：优秀论文常加「问题分析」独立一节，末尾放技术路线总图收束；也可加「文献综述」一节点明本文定位。

## 二、各节写法要点

### 问题重述
- 不要照抄原文，要提炼；用 itemize 列各问。
- 背景写工程/实际价值 + 简要原理。

### 模型假设
- 3-6 个**具体**假设，后文必须呼应；每条给「成立理由 + 影响评估」。
- 严禁"忽略其他次要因素"这类模糊表述。

### 符号说明
- 三线表分组列出；符号全程统一，用角标表达阶段状态，不要 ABC 乱代替。

### 模型建立与求解（核心）
- **闭环论证链**：题意理解 → 数据处理 → 模型建立 → 求解验证 → 结论解释，每一步回答"为什么这样做""结果为何可信"。
- 数学表达：**严禁只用文字描述想法**，必须给出公式、判别式、符号说明。
- 每个问题用不同/递进方法；从简单模型演进到最终模型，被淘汰的中间模型也要写（说明探索过）。

### 结果分析
- 不止给数值：要含误差分析、灵敏度分析、图表支撑。
- **图题直接点结论**（写"XX处理后误差降至 X"而非"拟合效果图"）。
- 只保留有支撑的模型，多模型比较要突出自己模型的优越性。

### 模型评价
- 优点 + 不足 + 改进方向，都要写。

### 结论
- 分条 (1)(2)(3)，每条对应一问题 + 具体数值。

## 三、写作范式

- **摘要第一天就开始写，改 3 版以上**，由最熟悉模型的建模手主笔。
- 论文一问一问同步写，**不能堆到最后**。
- 正文 20-25 页左右为宜（代码字号可缩小，附录不计页数）。
- 每个术语紧跟具体操作，禁止空洞堆词（不能只写"联合反演"，要写"同时用 10° 和 15° 两组谱估计同一厚度"）。

## 四、高频写作问题（来自 448 条评阅意见）

1. 摘要无数值结果 / 无结果讨论（最高频 ~26%）。
2. 写作表达差、"描述性太多"、口语化。
3. 建模过程不清楚。
4. 缺少结果讨论 / 模型评价。
5. 章节序号混乱、页码错误。
6. 正文插入代码（应放附录）、程序运行截图。
7. 公式不编号、公式后无标点、公式字体不对、公式截图。
8. 符号不统一，导致后期返工。
